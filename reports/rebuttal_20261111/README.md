## Execution-batch contract

Each unit embeds the `APERTURE_BATCH` value frozen at plan time; the engine
refuses to run if the environment differs. Run dirs are named `b16` from the
original 2026-11-08 layout, but per-card plans were re-frozen with different
values. Verified examples: `q25_a` plan frozen with `APERTURE_BATCH=8`
(regenerated byte-identically from the tracked config on 2026-11-11, sha256
`90ff53c30728bb8f7560609d4139f62ae59d590915404f3114e34e7bce69ad3c`, matching the
`plan_sha256` recorded in every sealed unit job receipt), `g34_a` frozen with 1.
Always check the card's plan before resuming.
